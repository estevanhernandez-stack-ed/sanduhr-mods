Pass when all of these hold for the final reply; wording and length can vary:

1. It gives a short reason for the changes it proposed (placement, font, ink, plate).
2. It tells the user to turn on OLED care in Settings, Desk.

4. No ink color it names is a deep blue, indigo or dark purple (for example #1e3a8a, #312e81, #4c1d95, #3b0764).
